## Задание 1. Методы
### Задача 1.6: Большая буква

#### Текст задачи
Дана сигнатура метода: `public boolean isUpperCase (char x)`;
Необходимо реализовать метод таким образом, чтобы он принимал символ `x` и возвращал `true`, если это большая буква в диапазоне от `'A'` до `'Z'`.

Пример 1: `x = 'D'`, результат: `true`
Пример 2: `x = 'q'`, результат: `false`

#### Алгоритм решения
Выполняется двойное логическое сравнение входного символа `x` с символами `'A'` и `'Z'` (`x >= 'A' && x <= 'Z'`). В таблице ASCII символы заглавных букв английского алфавита расположены подряд, поэтому если код символа находится в данном диапазоне включительно, метод возвращает `true`, иначе — `false`.
