#### Текст задачи
Дана сигнатура метода: `public boolean isUpperCase (char x)`;
Необходимо реализовать метод таким образом, чтобы он принимал символ `x` и возвращал `true`, если это большая буква в диапазоне от `'A'` до `'Z'`.

#### Текст задачи
Дана сигнатура метода: `public boolean isInRange (int a, int b, int num)`;

Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если `num` входит в указанный диапазон (включая границы). Затем выполняется проверка попадания числа `num` в полученный интервал включительно (`num >= min && num <= max`), и результат логического выражения возвращается из метода.

#### Алгоритм решения

Если хотя бы один из остатков равен нулю (`a % b == 0 || b % a == 0`), значит, одно число делится нацело на другое, и метод возвращает `true`.

Вторым циклом `for` проверяется каждый элемент `arr[i]`: если он равен `x`, его индекс `i` сохраняется в `result[index]`, после чего `index` увеличивается на 1. ### Задача 4.10: Удалить негатив

#### Алгоритм решения
Первым циклом `for-each` подсчитывается количество неотрицательных элементов (`value >= 0`) для вычисления размера нового массива `count`. Далее создается массив `result` размера `count`. Вторым циклом `for-each` неотрицательные значения поочередно копируются в `result` с использованием вспомогательного счетчика `index`. Сформированный массив без отрицательных чисел возвращается из метода.
